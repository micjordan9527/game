# Prompt 1：项目定位和内容边界

请把当前项目理解为一个中文行业科普知识站。

网站内容方向包括：

- 博彩行业
- 体育博彩
- 包网
- 产品设计
- 运营增长
- UI / UX 设计
- 技术开发
- 运维
- 风控
- 后台系统
- 代理体系
- 支付
- 钱包
- 游戏厂商
- 活动系统
- 数据报表

网站不是赌博推广站，不引导用户充值下注，不写“稳赚”“暴利”“带人下注”等内容。

网站定位：

> 用白话解释 + 专业拆解 + 图解表达 + 模板沉淀的方式，把博彩、体育、包网行业知识做成一个外行能看懂、内行觉得专业的网站。

文案语气：

- 专业但容易懂
- 不夸张营销
- 多用“一句话解释”“业务场景”“图解说明”
- 关注产品结构、运营方法、设计体验、技术架构、运维风控
- 不提供规避监管、绕过风控、作弊套利、攻击平台、洗钱等内容
