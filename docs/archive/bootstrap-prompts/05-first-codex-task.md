# Prompt 5：第一阶段 Codex 开发任务

请根据本交接包，直接开始实现第一阶段。

## 第一阶段目标

搭建一个可以运行的中文科普知识站基础版本。

## 必须完成

1. 检查当前项目结构。
2. 判断是否已有 Next.js / React / Tailwind。
3. 如果没有，创建合适结构。
4. 建立或移动 data 数据文件。
5. 建立通用组件。
6. 建立页面路由。
7. 接入 mock 数据。
8. 实现首页。
9. 实现栏目页。
10. 实现术语库页。
11. 实现模板库页。
12. 实现文章详情页。
13. 保证项目能运行。
14. 最后给出修改文件列表和运行方式。

## 暂时不做

- 登录注册
- CMS
- 数据库
- 用户评论
- 支付
- 下载功能
- 多语言
- 真正的图片生成
- 复杂权限系统

## 验收标准

1. 首页 30 秒内能让人理解这个网站是做什么的。
2. 外行能看懂栏目入口。
3. 文章页适合长文阅读。
4. 术语库能快速查概念。
5. 模板库像一个可复用工作资料库。
6. 整体不像赌博推广站，而像行业知识库。
7. 页面在手机上能正常阅读。
8. mock 数据集中管理。
9. 没有明显的违法、诱导下注、规避风控类文案。
