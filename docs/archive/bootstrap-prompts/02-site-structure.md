# Prompt 2：页面结构和路由

请实现以下页面：

```txt
/
首页

/industry
行业入门

/sportsbook
体育博彩

/white-label
包网科普

/product
产品设计

/operation
运营增长

/design
设计体验

/development
技术开发

/devops-risk
运维风控

/glossary
术语库

/templates
模板库

/articles/[slug]
文章详情页
```

首页结构：

```txt
Hero 区
↓
项目一句话介绍
↓
核心栏目入口
↓
推荐先读文章
↓
术语库入口
↓
模板库入口
↓
专业视角说明
↓
底部联系 / 合作入口
```

栏目页要求：

- 展示栏目标题、栏目说明、推荐文章列表。
- 页面风格保持知识库 / SaaS 文档风格。
- 不要做成博彩推广落地页。

术语库页要求：

- 支持关键词搜索。
- 支持分类筛选。
- 术语卡片展示：术语、分类、一句话解释、常见场景、相关功能、容易误解。

模板库页要求：

- 支持按分类展示。
- 模板卡片展示：标题、描述、分类、章节。
- 后续可以扩展复制按钮和下载能力。

文章详情页要求：

- 支持 Markdown / MDX。
- 展示标题、摘要、分类、标签、阅读对象、难度。
- 支持长文阅读。
- Mermaid 可以先用代码块展示。
