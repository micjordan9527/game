# BM赛事列表样板

## 范围与依据

- 延续Sites v49（public），源码基线e2b7939866fd94c458683c48c87018578cad367c。
- 修改前保留checkpoint-before-bm-sample-20261030-v49和/workspace/work/bm-sample-v49-source.tar.gz。
- 本批只重做BM一个案例，保留已有URL、长图、局部、原型和旧锚点；未增加文章数量。
- 来源首页长图1600×1160，嵌入旧界面局部310×181、生成提案295×207。左右为不同赛事，不作同场效果证据。
- 原局部能确认日期/时间、双方队名和盘口列，无法确认比分；不沿用早期图中文字的“比分不够克制”诊断。

## 新阅读顺序

1. 原材料两局部各3框/编号与即时短图注。
2. 同一MATCH-DEMO-001的两种排列，球队、赛况和盘口选项值相同。
3. 长队名与18px文字同时切换，完整保留内容、按可用宽度换行；说明这份方案的空间代价，不归因为单一变量。
4. 设计取舍：赛事身份、阶段与比分、盘口标题及选项关系。独赢的主平客三项不强行对应两支球队。
5. 独立分类/状态原型、其他局部、简化来源索引、完整原材料。

## 材料与覆盖

- 新16:10封面取自本页结构示意并标注，脚本capture-bm-case-cover.mjs及public/images/cases/bm-reading-cover.source.json记录来源。
- 复用已有LongImageGallery，新增可选的原坐标标注、局部预览宽度与短注；没有标注参数的既有图集行为不变。
- 不虚构用户访谈、上线结果、误读率或效率提升。示意数值固定，无交易行为。
- 独立复核纠正了“分组必然更高”的过度归因，并给每张手机原图单独加编号图注。

## 后续材料顺序

- U8：个人中心余额、充提入口与收益分组，优先使用现有原始局部标注。
- TG：保持用户两段现有视频；不同主题不能合成同条推送，不恢复用户已删除的截图/按钮位置拆解。
- 后台：9张现有导览是本地演示截图；会员筛选等存在错置字段，先选择字段可信的一页再做列表/详情说明。
